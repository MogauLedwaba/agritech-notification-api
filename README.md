# AgriTech Notification API

Notification API for the AgriTechSystem project.

This API manages notifications for suppliers and group orders and includes an **AI Notification Service implemented using Ollama and the DeepSeek `deepseek-r1:1.5b` model**.

## Features

* Check if the API is running
* Get all notifications
* Get notifications for a supplier
* Create a notification
* Mark notifications as read
* Generate AI-assisted notification messages
* Connect the Notification API to the Ollama AI service
* Run the API and AI service using Docker

## AI Notification Service

The Notification API includes an AI service that connects to **Ollama** to generate notification messages.

The AI service uses the:

```text
Ollama
    ↓
DeepSeek deepseek-r1:1.5b
```

The Java `AiService` sends a prompt to Ollama and returns the generated AI response.

### AI Request Flow

```text
Client
   ↓
POST /api/notifications/ai
   ↓
AiController
   ↓
AiService
   ↓
Ollama
   ↓
DeepSeek deepseek-r1:1.5b
   ↓
AI-generated notification
```

## Endpoints

| Method | Endpoint                                   | Purpose                                  |
| ------ | ------------------------------------------ | ---------------------------------------- |
| `GET`  | `/api/notifications/health`                | Check if the API is running              |
| `GET`  | `/api/notifications`                       | Get all notifications                    |
| `GET`  | `/api/notifications/supplier/{supplierId}` | Get notifications for a supplier         |
| `POST` | `/api/notifications`                       | Create a notification                    |
| `PUT`  | `/api/notifications/{id}/read`             | Mark a notification as read              |
| `POST` | `/api/notifications/ai`                    | Generate an AI notification using Ollama |

## AI Notification Request

Send a POST request to:

```text
http://localhost:3002/api/notifications/ai
```

Example request:

```json
{
  "prompt": "Give me a short notification telling a farmer that their group order is ready."
}
```

Example response:

```json
{
  "response": "Subject: Group Order Ready..."
}
```

The response is generated by the configured Ollama model.

## Ollama Configuration

The AI service connects to Ollama using the `OLLAMA_BASE_URL` environment variable.

Default local configuration:

```text
OLLAMA_BASE_URL=http://localhost:11434
```

When the Notification API runs inside Docker, the Docker Compose configuration uses:

```text
OLLAMA_BASE_URL=http://host.docker.internal:11434
```

The configured AI model is:

```text
deepseek-r1:1.5b
```

## Running the API

Run the Spring Boot application using:

```bash
mvn spring-boot:run
```

The Notification API runs on the configured Spring Boot port.

## Testing the AI Service

PowerShell example:

```powershell
$body = @{ prompt = "Give me a short notification telling a farmer that their group order is ready." } | ConvertTo-Json

Invoke-RestMethod `
  -Uri "http://localhost:3002/api/notifications/ai" `
  -Method POST `
  -ContentType "application/json" `
  -Body $body
```

A successful request returns an AI-generated notification.

## Docker

The project includes a `Dockerfile` and `docker-compose.yml` for running the Notification API.

The Docker configuration connects the Notification API to the Ollama AI service.

The AI service can therefore be used while the Notification API is running inside a Docker container.

### AI Components

**`AiController.java`**

Exposes the AI endpoint:

```text
POST /api/notifications/ai
```

**`AiRequest.java`**

Receives the prompt sent to the AI service.

**`AiService.java`**

Connects the Java Notification API to Ollama and sends the prompt to the configured DeepSeek model.
